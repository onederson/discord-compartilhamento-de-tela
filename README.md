# Discord Compartilhamento de Tela

Este projeto permite o compartilhamento de tela através do Discord utilizando uma interface web e um servidor. Ele foi originalmente desenvolvido como "Discord Screenshare", e esta versão foi renomeada e adaptada para português.

## Instalação e Execução

Para iniciar o projeto:
1. Instale as dependências com `npm install`
2. Inicie com `npm start`
